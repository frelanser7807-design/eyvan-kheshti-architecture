# Eyvan Kheshti — Cinematic Architecture Website

نسخهٔ قابل‌انتقال سایت حرفه‌ای «ایوان خشتی» با روایت ویدئویی کلیکی، محتوای عمومی انگلیسی، پنل مدیریت خصوصی، PWA و لایهٔ آمادهٔ اتصال به بک‌اند و اپلیکیشن.

## وضعیت واقعی پروژه

- سایت و تجربهٔ سینمایی: فعال در پیش‌نمایش محلی
- پنل مدیریت: فعال در حالت دمو و ذخیره روی همان مرورگر
- متن روی ویدئوها: پنج فصل انگلیسی/فارسی مستقل در بخش «متن روی ویدئو» پنل
- اتصال اپ: قرارداد API و Data Adapter آماده؛ بک‌اند آنلاین هنوز متصل نشده است
- Explore: پروژه‌ها، آموزش‌ها، مطالب معماری، دوره‌ها و خبرنامه فعال در پیش‌نمایش
- زبان: انگلیسی پیش‌فرض و فارسی اختیاری؛ پنل مدیریت خصوصی فارسی
- تایپوگرافی فیلم: پنج فصل مستقل و قابل‌ویرایش از پنل، با متن‌های واقعی مؤسس، خدمات، حوزهٔ پروژه، متریال و فرایند
- صدا: موسیقی سینمایی الکترونیک اختصاصی ۱۳۲ BPM، با انرژی و ضرب نزدیک به رفرنس اما بدون کپی فایل یا ملودی آن؛ شروع پس از نخستین کلیک طبق محدودیت مرورگر
- انتشار عمومی فعلی: `https://courageous-jalebi-d0280a.netlify.app`
- دامنهٔ اختصاصی: هنوز خریداری و متصل نشده است

## چرا لینک 127.0.0.1 برای دیگران باز نمی‌شود؟

`127.0.0.1` یعنی «همین کامپیوتر». این آدرس فقط روی دستگاهی کار می‌کند که سرور پیش‌نمایش روی آن روشن است. برای ارسال لینک به دیگران باید پوشهٔ `dist` روی یک هاست عمومی منتشر و دامنه به آن متصل شود.

## اجرای محلی

1. Node.js 20 یا جدیدتر نصب باشد.
2. در پوشهٔ پروژه `npm install` اجرا شود.
3. `npm run dev` اجرا شود.
4. آدرس نمایش‌داده‌شده در مرورگر باز شود.

پنل مدیریت از مسیر `#/admin` در همان آدرس در دسترس است.

## بازیابی خودکار رسانه‌ها

برای انتقال مطمئن از مسیر GitHub Connector، رسانه‌های بزرگ به قطعات بدون افت کیفیت در `media-parts/` نگهداری می‌شوند. دستورهای `npm run dev` و `npm run build` پیش از اجرا، ویدئوها، تصاویر و صداهای اصلی را به‌صورت خودکار بازسازی و با SHA-256 راستی‌آزمایی می‌کنند. برای بررسی یا بازیابی مستقیم نیز می‌توان `npm run media:restore` را اجرا کرد.

## ساخت نسخهٔ آمادهٔ هاست

1. `npm run build`
2. `npm run smoke`
3. تمام محتوای پوشهٔ `dist` در ریشهٔ هاست بارگذاری شود.

خروجی‌های قدیمی و میانی فیلم بدون حذف در `archive/legacy-film` و `archive/legacy-public-assets` نگهداری می‌شوند و وارد بستهٔ عمومی `dist` نمی‌شوند. ۳۱ فایل قدیمیِ دیگر نیز از نسخهٔ عمومی جدا شده‌اند. بستهٔ نهایی فعلی حدود ۳۲٫۲ مگابایت است؛ درحالی‌که پیش از پاک‌سازی حدود ۹۱٫۴ مگابایت بود.

## صدا

صدای بادمانند قبلی کنار گذاشته شده و یک قطعهٔ موسیقی سینمایی اختصاصی ۴۸ ثانیه‌ای جایگزین آن است. قطعه از پدهای تونال، کلیدهای ضربی و پرکاشن کنترل‌شده استفاده می‌کند و نویز محیطی ندارد. مرورگرها پخش خودکار صدا را پیش از تعامل کاربر مسدود می‌کنند؛ بنابراین صدا پس از «Click to Begin» آغاز می‌شود و از کلید `SOUND ON/OFF` قابل‌کنترل است.

## پنل، بک‌اند و اپ

در حالت فعلی پنل برای پیش‌نمایش از Local Storage استفاده می‌کند. نسخهٔ تجاری نیازمند ورود امن مدیر، دیتابیس، فضای ذخیرهٔ رسانه و API آنلاین است. قرارداد لازم در `docs/API_CONTRACT.md` و برنامهٔ اپ در `docs/APP_PLAN.md` قرار دارد.

## اتوماسیون محتوا

پایهٔ نسخهٔ رایگانِ سیستم Agentic در `agent-system/` آماده شده است: Make زمان‌بندی را انجام می‌دهد، Composio فقط اتصال کم‌دسترسی به Google Drive و GitHub را فراهم می‌کند، و Gemini در سهمیهٔ رایگان پیش‌نویس دوزبانه می‌سازد. تا زمانی که اتصال‌ها و متغیرهای امن در Netlify تنظیم نشوند، سیستم فقط آماده‌سازی و اعتبارسنجی محلی دارد. برای بررسی پایه اجرا کنید: `npm run agent:validate`.

## فروش و پرداخت

مدل دوره/محصول، بخش فارسی «فروش و پرداخت»، تنظیم Etsy و قرارداد فنی سفارش آماده شده‌اند. Stripe، PayPal، Zarinpal و IDPay به‌صورت Adapter مستقل پیش‌بینی شده‌اند، اما درگاه واقعی عمداً فعال نشده است. انتخاب درگاه به کشور قانونی فعالیت، کشور حساب بانکی، ارز و شرایط احراز هویت ارائه‌دهنده بستگی دارد. جزئیات مرحلهٔ production در `docs/COMMERCE_BACKEND_PLAN.md` ثبت شده است.

## سئو

نسخهٔ فعلی متادیتای انگلیسی، OpenGraph، robots، مجوز OAI-SearchBot و Schema پایه دارد. پس از انتخاب دامنه باید canonical، sitemap، Search Console، صفحات مستقل پروژه و مقاله و اندازه‌گیری Core Web Vitals تکمیل شود؛ حضور در نتیجهٔ Google یا ChatGPT قابل تضمین نیست.

## ویرایش بعد از انتشار

بله. تا زمانی که این پوشهٔ سورس و دسترسی هاست یا مخزن حفظ شود، سایت بعد از انتشار هم قابل‌ویرایش است. تغییرات در سورس انجام، دوباره build و روی هاست جایگزین می‌شوند. برای ویرایش محتوایی بدون کدنویسی، باید پنل به بک‌اند واقعی متصل شود.

## تصمیم انتشار

نسخهٔ فعلی یک Release Candidate محلی و آمادهٔ انتقال به staging است، نه انتشار عمومی نهایی. فهرست دقیق ورودی‌ها و دروازه‌های باقی‌مانده در `docs/LAUNCH_CHECKLIST.md` قرار دارد.
