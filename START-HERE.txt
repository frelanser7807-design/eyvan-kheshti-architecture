EYVAN KHESHTI — WEBSITE PACKAGE

این پوشه شامل سورس کامل، ویدئوها، نسخهٔ آمادهٔ هاست، پنل دمو و اسناد پروژه است.

پیش‌نمایش محلی:
1) Node.js 20 یا جدیدتر نصب باشد.
2) در این پوشه npm install اجرا شود.
3) npm run dev اجرا شود.

نسخهٔ آمادهٔ هاست در پوشهٔ dist قرار می‌گیرد.
پنل دمو از آدرس #/admin باز می‌شود.

نکته‌های مهم:
- پنل فعلی محلی است و برای نسخهٔ تجاری به بک‌اند، ورود امن و دیتابیس نیاز دارد.
- لینک 127.0.0.1 فقط روی همان کامپیوتر باز می‌شود.
- صدای آزمایشی بادمانند غیرفعال است و موسیقی حرفه‌ای نهایی باید انتخاب شود.
- برای جزئیات فنی و مسیر انتشار، README.md و پوشهٔ docs را ببینید.
