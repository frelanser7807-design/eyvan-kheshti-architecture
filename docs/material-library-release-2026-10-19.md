# Material Library initial release

Owner authorised publication of the existing working collection, with additional
wood models to follow separately. This release includes 4K only; 16K files and
native software exports remain unreleased and are not advertised as available.

Independent library → material family → type → product. One original fluted wood
collection has seven finish studies, three fixed photographic-style room views,
interactive PBR sphere/panel lighting, and 4K texture and preview downloads.
Rooms are 1254px AI-assisted illustrative scenes; surface lighting does not relight
the rooms. Product characteristics are digital design data, not certified supplier
specifications. Source CC0 1K samples are separately labelled and preserved.

Changes are integrated onto GitHub HEAD 07f921deb09249e82f4654dd639e028e85450616,
not the older dirty local checkout. Existing articles, video routes, social links,
newsletter worker and homepage video are preserved. Library is linked separately
from Projects. Empty material categories/types are noindex and excluded from sitemap.

Original asset authoring uses the included procedural generator (no image upscaling).
Manifest SHA-256 records and dimensions accompany all seven 4K finishes. The actual
white finish browser ZIP download passed CRC validation with all six files present.
Category routes, search, seven finish controls, three room views, light direction,
shape switching and 1440px/390px overflow were checked locally. CI must run the full
site build and regression tests before a preview/production deployment.

## Rollout gates
1. Pull-request full build, existing regression tests and material collection tests.
2. Preview HTML, media, 4K map integrity, desktop/mobile interaction checks.
3. Confirm main has not advanced unexpectedly; merge only after passing preview.
4. Production workflow and real domain verification; record URLs and deployment IDs.

No newsletter issue is created or scheduler resumed. No private configuration,
secrets, incomplete 16K chunks or oversized prebuilt ZIPs are included.
