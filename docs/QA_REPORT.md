## محدودیت‌های فعلی

1. لینک `127.0.0.1` فقط روی کامپیوتر میزبان کار می‌کند.
2. تغییرات پنل فعلاً در همان مرورگر ذخیره می‌شوند.
3. برای لینک عمومی باید `dist` روی هاست منتشر شود.
4. برای پنل واقعی و اپ مشترک باید بک‌اند API راه‌اندازی شود.
5. درگاه، سفارش واقعی، ایمیل تأیید، صفحات حقوقی و حساب مدیر فقط پس از انتخاب کشور و بک‌اند production فعال می‌شوند.
