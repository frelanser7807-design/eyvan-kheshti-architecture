# برنامهٔ اتصال اپلیکیشن ایوان خشتی

## هدف

سایت، پنل مدیریت و اپ موبایل باید یک منبع دادهٔ مشترک داشته باشند. پنل محتوا را در بک‌اند ذخیره می‌کند و سایت و اپ همان داده را از API دریافت می‌کنند.

## نسخهٔ نخست اپ

1. صفحهٔ معرفی استودیو
2. فهرست و جزئیات پروژه‌ها
3. خدمات معماری
4. گالری تصویر و ویدئو
5. فرم شروع پروژه
6. اطلاعات تماس و شبکه‌های اجتماعی
7. اعلان اختیاری برای پروژه یا خبر تازه

## داده‌های مشترک

- Brand / Studio profile
- Services
- Projects and media
- Contact details
- Leads / project enquiries
- Content version and update time

## معماری پیشنهادی

- یک API نسخه‌بندی‌شده روی HTTPS
- احراز هویت مدیر با نقش و نشست امن
- دیتابیس برای متن، پروژه و درخواست‌ها
- Object Storage برای تصویر، ویدئو و poster
- CDN برای تحویل رسانه
- اپ React Native/Expo یا Flutter؛ انتخاب نهایی پیش از شروع اپ انجام می‌شود

## وضعیت فعلی

`API_CONTRACT.md` و Data Adapter سایت آماده‌اند. اتصال واقعی، حساب بک‌اند، کلیدها، دیتابیس، آپلود رسانه و اعلان هنوز پیاده‌سازی نشده‌اند و قبل از استفادهٔ تجاری باید در staging تست شوند.
