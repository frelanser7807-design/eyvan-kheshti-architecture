# برنامهٔ SEO و دیده‌شدن در موتورهای جست‌وجو

## آماده در نسخهٔ فعلی

- محتوای عمومی انگلیسی و عنوان/توضیح هدفمند
- robots با اجازهٔ خزیدن موتورهای عمومی و OAI-SearchBot
- OpenGraph و Twitter Card
- Schema.org نوع ProfessionalService
- متن HTML پایه برای خزنده‌ها و تجربهٔ بدون جاوااسکریپت
- نام‌گذاری خدمات معماری، داخلی، نما و تجسم معماری

## بعد از خرید دامنه

1. ثبت `VITE_SITE_URL` و canonical قطعی
2. ساخت sitemap با URL واقعی و ثبت در Google Search Console و Bing Webmaster Tools
3. ساخت URL مستقل و قابل ایندکس برای هر پروژه، آموزش، مقاله و دوره
4. افزودن Schema مناسب Article، CreativeWork، Course و Breadcrumb
5. بهینه‌سازی poster/video، lazy loading و Core Web Vitals
6. اتصال آنالیتیکس با رضایت و سیاست کوکی متناسب
7. انتشار منظم محتوای اصیل مبتنی بر تخصص واقعی، لینک‌دهی داخلی و معرفی نویسنده
8. پایش 404، redirect، index coverage، عبارت‌های جست‌وجو و conversion

هیچ توسعه‌دهنده‌ای نمی‌تواند رتبهٔ Google یا نمایش در پاسخ ChatGPT را تضمین کند. امکان خزیدن، محتوای مفید، اعتبار برند و دسترسی پایدار فقط شانس دیده‌شدن را افزایش می‌دهند.
