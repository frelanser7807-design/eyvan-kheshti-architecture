# DESIGN DIRECTION

فضای معماری لوکس و معاصر با الهام از ساختمان‌های اداری لندن، رنگ‌های تیرهٔ کنترل‌شده، جزئیات طلایی گرم، ویدئوی تمام‌صفحه، تایپوگرافی ظریف و رابط حداقلی. تا زمان تأیید نشانی واقعی، سایت ادعای داشتن دفتر فیزیکی در لندن نمی‌کند. اطلاعات واقعی مؤسس، خدمات، حوزهٔ پروژه، متریال و فرایند به‌شکل دادهٔ دیجیتال روی فیلم تایپ می‌شوند و هر فصل از پنل فارسی مستقل ویرایش می‌شود.

# REFERENCE STRATEGY

MotionSite و ویدئوی مرجع فقط برای زبان حرکت، نظم صحنه‌ها و کیفیت ارائه استفاده شده‌اند. کد، رسانه، نام و هویت سایت اختصاصی است و از دارایی خام مرجع استفاده نمی‌کند.

# MOTION PLAN

- ورودی: کلیک یا لمس
- سرعت دو فصل اول: 1.2x؛ فصل ارائه و حرکت دست: 1.05x؛ فصل‌های بعدی: 1.35x
- هر کلیک یک فصل کامل را پخش می‌کند
- کارت‌ها روی پایان فیلم افتتاحیه ظاهر می‌شوند
- اطلاعات واقعی هر فصل با تایپ دیجیتال و پنل باریک نمایش داده می‌شوند
- reduced-motion برای کاربران حساس به حرکت در CSS پیش‌بینی شده است

# 3D PLAN

در نسخهٔ فعلی حس سه‌بعدی با ویدئوی سینمایی و لایه‌های دیجیتال ایجاد می‌شود. WebGL یا مدل آزاد سه‌بعدی جزو build فعال نیست. در آینده می‌توان یک مدل GLB سبک با poster fallback اضافه کرد، مشروط به نیاز واقعی و بودجهٔ عملکرد.

# TECH STACK

- React 19 + Vite
- CSS سفارشی و responsive
- ویدئوی محلی MP4 و موسیقی سینمایی الکترونیک اختصاصی ۱۳۲ BPM، با حس ریتمیک رفرنس اما بدون کپی فایل یا ملودی آن
