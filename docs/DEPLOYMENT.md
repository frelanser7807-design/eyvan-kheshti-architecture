# راهنمای انتشار روی هاست و دامنه

## خروجی قابل انتشار

- فرمان ساخت: `npm run build`
- کنترل نهایی: `npm run smoke`
- پوشهٔ قابل آپلود: `dist`
- پنل مدیریت: `https://YOUR-DOMAIN.COM/#/admin`

## انتشار مستقل بدون بک‌اند

برای نمایش عمومی نسخهٔ فعلی، تمام فایل‌های داخل `dist` را در پوشهٔ عمومی هاست بارگذاری کنید. این نسخه سایت، ویدئو، صدا و پنل دموی محلی را نمایش می‌دهد؛ اما تغییرات پنل میان دستگاه‌ها مشترک نیست.

## انتشار تجاری با پنل واقعی و اپ

1. بک‌اند مطابق `API_CONTRACT.md` پیاده‌سازی شود.
2. ورود امن مدیر، دیتابیس، ذخیرهٔ رسانه و محدودسازی فرم فعال شود.
3. فایل `.env` از روی `.env.example` ساخته شود.
4. `VITE_DATA_MODE=remote` تنظیم شود.
5. `VITE_API_BASE_URL` به آدرس HTTPS بک‌اند اشاره کند.
6. نسخهٔ تازه build و روی staging آزمایش شود.
7. پس از تأیید، دامنه و SSL متصل شوند.

## دامنه دات‌کام

دامنه می‌تواند از هر ثبت‌کننده‌ای تهیه شود و با DNS به هاست متصل گردد. خرید دامنه، انتخاب پلن، ورود به حساب هاست و تغییر DNS فقط پس از تأیید صاحب پروژه انجام می‌شود. دامنه باید قبل از انتشار در metadata، canonical، robots، sitemap و تنظیمات CORS جایگزین شود.

## ویرایش پس از انتشار

- تغییرات طراحی و ویدئو: در سورس انجام، دوباره build و deploy می‌شوند.
- تغییرات متن و پروژه: پس از اتصال پنل واقعی، بدون build از پنل ذخیره می‌شوند.
- اپلیکیشن: همان API را می‌خواند؛ تغییر محتوای پنل هم‌زمان در سایت و اپ دیده می‌شود.

## برگشت به نسخهٔ سالم

پیش از هر انتشار، پوشهٔ `dist` تأییدشده و فایل محتوای JSON پشتیبان‌گیری شوند. اگر نسخهٔ تازه مشکل داشت، آخرین build تأییدشده دوباره روی هاست قرار می‌گیرد.
